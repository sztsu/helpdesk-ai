Motor de Inferência · API Gemini (Opcional)

O HelpDesk AI 2.0 funciona completo em modo local determinístico + RAG sem precisar de chave. Se desejar conectar o Google Gemini 2.5 Flash ao vivo durante a apresentação, informe sua API Key abaixo.

Privacy by Design: a chave nunca é gravada no código-fonte nem enviada ao GitHub; ela é apagada automaticamente ao fechar a aba do navegador. Caso a API retorne HTTP 503, o agente aciona fallback automático.
